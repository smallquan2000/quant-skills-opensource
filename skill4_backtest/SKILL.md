# Skill 4 · 轻量级回测引擎

## 1. 这个 Skill 做什么

**100% 纯离线**：不联网、不读实时行情、不用任何第三方库。读一份长表历史 CSV，逐交易日复用 Skill 2 的 `weights.json` 打分 → 取 TopN → 等权持有 → 按 `forward_return_pct` 结算 → 扣双边手续费 → 输出净值曲线与绩效报告。

## 2. 依赖安装

```bash
python3 -m pip install -r requirements.txt   # 全部为注释，可直接跳过
```

## 3. 配置方法

```bash
cp config.example.json config.json   # 可选
python3 scripts/make_sample_data.py   # 首次运行：生成合成演示数据
python3 scripts/backtest.py
```

| 配置键 | 说明 |
| --- | --- |
| `weights_file` | 默认本目录副本；改成 `../skill2_scoring_engine/weights.json` 可与 Skill 2 共用单一权重源 |
| `input.history_csv` | 长表历史 CSV |
| `input.forward_return_column` | 未来收益列，单位**百分点** |
| `backtest.top_n` / `commission_rate` / `initial_capital` | 每期持仓数 / 双边费率 / 起始资金 |
| `backtest.start_date` / `end_date` | 回测区间 |
| `output.*` | 净值 CSV / 绩效 JSON / 可读 MD |

> ⚠️ `data/sample_history.csv` 由固定随机种子生成，是**合成演示数据，不是真实行情**，仅用于验证流程，切勿据此判断策略优劣。

## 4. 运行方式（Python）

```bash
python3 scripts/backtest.py
python3 scripts/backtest.py --history data/my_history.csv --start 2026-11-02 --end 2026-11-13 --top 3
```

**防失真设计**：交易日少于 60 日时，`annualized_return_pct` 自动置为 `null` 并在报告注明原因 —— 短样本年化会指数级放大（10 日样本可算出数万 %），直接展示会严重误导。

## 5. 输入 / 输出契约

**输入 CSV（长表）**：每日每只一行，需含 `weights.json` 中各因子 `column` 列 + `forward_return_pct`。

**输出**：`equity_curve.csv`（逐日净值/回撤/入选代码）、`backtest_report.json`（含 `daily_picks`）、`backtest_report.md`（可读报告）。

指标：累计收益、年化收益（样本不足则 N/A）、最大回撤、日胜率、交易胜率、夏普比率、交易笔数、期末资金。

## 6. ★ 纯文本 Prompt 模板（给无法运行 Python 的 AI）

> 复制整段 + 贴入历史数据，豆包 / Claude 无需运行代码即可逐日推演出净值曲线与绩效。模板内已自包含完整的打分分段表。

```text
【开始】
你现在扮演「轻量级离线回测引擎」。请不要运行代码，严格按下面的规则逐交易日手工推演，
输出净值曲线与绩效指标。全程离线，不要联网、不要编造数据。

【一、输入格式（长表）】
每天每只标的一行：date, code, name, price, stock_change_pct, cb_stock_gap,
volume_ratio, premium_rate, forward_return_pct
forward_return_pct 单位为百分点（2.0 表示 +2.0%）。

【二、硬过滤（三条同时满足才入选）】
100 <= price <= 150；stock_change_pct >= 3.0；volume_ratio >= 1.5

【三、五维打分（区间 min <= x < max，null 表示无穷；命中即取该档）】
S1 价格位置 w=0.15: x<110→1.00 | 110~125→0.85 | 125~140→0.60 | 140~150→0.35 | >=150→0.00
S2 正股动量 w=0.25: x<0→0.00 | 0~3→0.30 | 3~5→0.70 | 5~8→0.90 | >=8→1.00
S3 债股缺口 w=0.25: x<0→0.00 | 0~1→0.35 | 1~2→0.60 | 2~4→0.85 | >=4→1.00
S4 量比     w=0.20: x<1.0→0.00 | 1.0~1.5→0.30 | 1.5~2.0→0.60 | 2.0~3.0→0.85 | >=3.0→1.00
S5 溢价率   w=0.15: x<5→1.00 | 5~10→0.85 | 10~20→0.60 | 20~30→0.35 | >=30→0.10
score = 100 × (0.15×S1 + 0.25×S2 + 0.25×S3 + 0.20×S4 + 0.15×S5)，保留 2 位。

【四、逐日推演规则】
1. 按 date 分组，每日先过【二】硬过滤，再按【三】打分降序取 TopN（本例 TopN=2）。
2. 当日组合收益 = 入选标的 forward_return_pct 的算术平均 - 双边手续费
   手续费 = 0.0003 × 100 × 2 = 0.06（百分点），即每天固定扣 0.06%。
3. 净值 equity 初始 1.0，每日 equity = equity × (1 + 当日组合收益/100)。
4. 峰值 peak = 历史最大 equity；当日回撤 = (equity/peak - 1)×100。
5. 期末资金 = 50000 × 最终 equity。

【五、绩效计算】
累计收益率 = (最终 equity - 1)×100
最大回撤 = 所有交易日回撤中的最小值
日胜率 = 组合收益 > 0 的天数 / 总天数 × 100
交易胜率 = forward_return_pct > 0 的入选记录数 / 总入选记录数 × 100
年化收益率：若交易日 < 60 天，输出「N/A（样本不足）」，不要计算。

【六、演算示例（3 天 × 3 只，TopN=2）】
数据：
D1 A:120,5.0,3.0,2.0,8.0,fwd=+2.0 | B:135,4.0,2.5,1.8,12.0,fwd=-1.0 | C:105,1.0,0.5,1.0,25.0,fwd=+3.0
D2 A:fwd=-1.5 | B:fwd=+1.0 | C:fwd=+2.0
D3 A:fwd=+1.0 | B:fwd=-0.5 | C:fwd=-2.0
打分（3 天因子相同，故名次相同）：
A: S1=0.85(120) S2=0.90(5.0) S3=0.85(3.0) S4=0.85(2.0) S5=0.85(8.0)
   score=100×(0.1275+0.2250+0.2125+0.1700+0.1275)=86.25
B: S1=0.60(135) S2=0.70(4.0) S3=0.85(2.5) S4=0.60(1.8) S5=0.60(12.0)
   score=100×(0.0900+0.1750+0.2125+0.1200+0.0900)=68.75
C: 硬过滤淘汰（正股 1.0<3.0 且量比 1.0<1.5），fwd 再高也不入选。
→ 每天入选 A、B：
D1 组合收益 = mean(+2.0,-1.0) - 0.06 = +0.44%；equity = 1.0000×1.0044 = 1.004400
D2 组合收益 = mean(-1.5,+1.0) - 0.06 = -0.31%；equity = 1.004400×0.9969 = 1.001287
D3 组合收益 = mean(+1.0,-0.5) - 0.06 = +0.19%；equity = 1.001287×1.0019 = 1.003191
累计收益率 = +0.32%；最大回撤 = (1.001287/1.004400-1)×100 = -0.31%
日胜率 = 2/3 = 66.67%；交易胜率 = 3/6 = 50.00%
年化收益率 = N/A（样本仅 3 天，不足 60 天）
期末资金 = 50000 × 1.003191 = 50,159.55

【七、输出格式（三段）】
第 1 段：每日明细表（日期 | 通过过滤数 | 入选代码 | 组合收益 | 净值 | 回撤）
第 2 段：绩效汇总表（累计收益 | 年化 | 最大回撤 | 日胜率 | 交易胜率 | 交易笔数 | 期末资金）
第 3 段：一句话结论（策略在该区间的表现与样本局限性提示）

【八、约束】
- 必须先过滤再打分；被淘汰标的的 fwd 不得计入组合收益。
- 手续费每个交易日固定扣 0.06 个百分点。
- 不得联网、不得编造输入中不存在的标的或收益。
- 现在请对我下面给出的历史数据执行回测：
【结束】
```

## 7. 跨平台说明

| 平台 | 用法 |
| --- | --- |
| WorkBuddy / 本地 / CI | `python3 scripts/backtest.py`，完全离线 |
| GitHub 开源 | 本目录自带 `weights.json` 副本与数据生成器，可单独 clone |

## 8. 注意事项 & 免责声明

- 本引擎为**简化日频推演**，不含滑点、涨停限制、停牌、T+0 日内路径与撮合细节，结果不可等同于实盘。
- 样例数据为合成数据，仅供流程验证。
- 仅供策略研究，**不构成投资建议**。
